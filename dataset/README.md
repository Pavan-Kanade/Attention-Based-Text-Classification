# IMDb Large Movie Review Dataset

## Dataset Specifications
- **Name:** IMDb Large Movie Review Dataset
- **Total Samples:** 50,000 reviews
- **Classes:** Binary (Positive: 1, Negative: 0)
- **Split:**
  - **Training:** 40,000 reviews (80%)
  - **Validation:** 5,000 reviews (10%)
  - **Testing:** 5,000 reviews (10%)

## Download Instructions
Run the automated downloader script:
```bash
python download_imdb.py
```
